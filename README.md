# Junteng Liu — Homepage

This repository contains the source for Junteng Liu's personal academic homepage, forked from [AcademicPages](https://github.com/academicpages/academicpages.github.io) and renamed to `LJT-Homepage`.

## Site content

- `_pages/about.md` — personal details, education and academic background, research experience, skills and research interests, publications, and contact information.
- `_pages/publications.html` — publications list.
- `_pages/cv.md` — education, research experience, skills and research expertise, publications, and contact information.
- `_config.yml` — site title, description, repository settings, and sidebar contact/profile links.
